# Brand and tool icons

Files in this folder are unmodified SVGs. The names and logos are trademarks of their owners and appear here only to identify compatible tools.

## Lobe Icons (MIT, `LICENSE-lobe-icons`)

Package `@lobehub/icons-static-svg` 1.104.0, source https://github.com/lobehub/lobe-icons, files at `icons/<file>` (e.g. https://unpkg.com/@lobehub/icons-static-svg@1.104.0/icons/cursor.svg).

amp-color, cline, cursor, gemini-color, geminicli-color, github, githubcopilot, goose, junie-color, kilocode, kimi-color, opencode, qwen-color, roocode, windsurf.

## Simple Icons (CC0 1.0, `LICENSE-simple-icons.md`)

Source https://github.com/simple-icons/simple-icons, files at `icons/<file>`.

- 16.38.0: apple, fishshell, git, gnubash, linux, ubuntu, zedindustries, zsh.
- 11.0.0: powershell, visualstudiocode, windows, windowsterminal. Later releases dropped these four.

## Primer Octicons (MIT, `LICENSE-octicons`)

Package `@primer/octicons` 19.42.0, source https://github.com/primer/octicons. The 16px glyphs for pull request, merge, issue, check, comment, branch and commit are embedded as paths in `src/components/Icon.tsx` (`gh*` names), not stored as files.

## Not available

Aider (no Lobe or Simple Icons mark), Command Prompt (no mark; the terminal glyph is the fallback).
