# Brachio 0.2.0

Brachio is a lightweight desktop app that runs several coding agents (Claude Code and Codex) side by side, each in its own worktree, and asks for you only when a decision is needed.

This is a pre-alpha release.

## New

- Open as many agent and shell tabs as you like in one task, including several of the same agent ("Codex 2"). Open tabs come back after a restart. Ctrl+Shift+T (⌘T on macOS) opens the kind you used last.
- The "+" menu lists every shell found on your machine: PowerShell 7, Windows PowerShell, Command Prompt, Git Bash and each WSL distribution on Windows; your login shell and the shells in `/etc/shells` on macOS. Settings has a default shell choice with the same list.
- Add a project from the project picker or the sidebar "+": choose a folder, clone from a URL (https or ssh, with progress and cancel), or create a new project folder with Git initialized.
- Agent usage in the status bar: the five-hour limit with a bar and percentage, with the weekly limit and reset times in a popover.
- The Files panel shows a folder tree with search.

## Changed

- A quieter interface: icon buttons with tooltips in headers and toolbars, icon tabs in the side panel, one clear current-row style, grouped settings rows, and dropdown fields that show a chevron.
- Settings moved to a gear button at the bottom of the sidebar (Ctrl+, still works).
- Messages between agents are under an "Agent messages" icon in the tab row.
- Korean wording is shorter and plainer throughout.

## Fixes

- Command Prompt no longer shows `^[[?1;2c` after the prompt.

## Install

Download the installer for your platform from the assets of this release.

- Windows: run the installer (`.exe` or `.msi`).
- macOS: open the `.dmg` and move Brachio to Applications.

Each installer has a SHA-256 value listed in `SHA256SUMS.txt` in the same release. To check a download on Windows, run `certutil -hashfile <file> SHA256`; on macOS, run `shasum -a 256 <file>`.

Requirements: Git 2.38 or later, and your own Claude Code or Codex account. Brachio runs locally and does not provide agent accounts.

## Unsigned builds

The installers are not code signed.

- Windows: SmartScreen may show "Windows protected your PC". Select "More info", then "Run anyway".
- macOS: Gatekeeper may report an unidentified developer. Control-click Brachio in Applications, choose Open, and confirm. If the app is still blocked, allow it under System Settings, Privacy & Security.

## Known limits

The limits listed for 0.1.0 still apply. Agent usage is read from Claude Code's sign-in on Windows; reading it from the macOS Keychain is not supported yet.
