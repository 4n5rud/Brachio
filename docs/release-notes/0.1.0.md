# Brachio 0.1.0

Brachio is a lightweight desktop app that runs several coding agents (Claude Code and Codex) side by side, each in its own worktree, and asks for you only when a decision is needed.

This is the first public release and is pre-alpha.

## Main features

- Projects and tasks for Git repositories and plain folders. Git tasks get their own branch and worktree.
- Persistent terminals that keep running in a separate local runtime. Reconnect after closing the window, and recover a stopped runtime from saved screens and conversation resume.
- Review and Git: inspect changes and pull request status, comment on diff lines, stage, commit, push, and create pull requests.
- Approval bar inside the app for supported Claude Code permission requests, setup commands, QA runs, and child task creation.
- Lead and worker tasks with dependencies (`--after`) and handoffs. You approve or reject a handoff before dependent tasks can start.
- Messages between task sessions.
- QA runner that records its own result, so a handoff shows whether QA was verified.
- A `brachio mcp` server over stdio with four tools.
- Four color themes in light and dark (eight in total).

## Install

Download the installer for your platform from the assets of this release.

- Windows: run the installer (`.exe` or `.msi`).
- macOS: open the `.dmg` and move Brachio to Applications.

Each installer has a SHA-256 value listed in `SHA256SUMS.txt` in the same release. To check a download on Windows, run `certutil -hashfile <file> SHA256`; on macOS, run `shasum -a 256 <file>`.

Requirements: Git 2.38 or later, and your own Claude Code or Codex account. Brachio runs locally and does not provide agent accounts.

## Unsigned builds

The installers are not code signed.

- Windows: SmartScreen may show "Windows protected your PC". Select "More info", then "Run anyway".
- macOS: Gatekeeper may report an unidentified developer. Control-click Brachio in Applications, choose Open, and confirm. If the app is still blocked, allow it under System Settings, Privacy & Security.

## Known limits

- Automatic merging is not built.
- Tasks nested more than one level deep are not supported.
- Child tasks cannot be created in plain folders.
- Remote execution is not supported. Brachio runs agents and terminals on the local machine only.
- Linux is not supported as an app. CI runs the platform-independent Rust checks on Linux, but the desktop app shell is not built there.
- Agent status, approvals, and recovery depend on the agent and runtime.
- Brachio does not configure MCP for your agents automatically.
- The app targets Windows and macOS. CI runs the Rust checks on Windows, macOS, and Ubuntu, plus UI checks.
