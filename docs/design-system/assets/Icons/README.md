Brachio's own 16px stroke icons, copied from `ui/src/components/Icon.tsx`. These SVG files draw in a fixed grey ink `#8A8A96` so they show on both themes; in the app the `Icon` component draws the same paths in `currentColor`. 1.5px stroke, round caps and joins. Use them at 15px in buttons, 13px beside labels and 11px in meta lines.
