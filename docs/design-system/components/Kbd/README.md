# Kbd

A key cap that shows a keyboard shortcut.

## Use
- Inside buttons, the search field and menus, after the label.
- Show the platform's own keys: `⌘` `⌥` `⇧` on macOS, `Ctrl` `Alt` `Shift` on Windows. One Kbd per key.
- `meta` style at 500, `color-text-3`, 1px `color-line-strong` border with a 2px bottom edge, radius `radius-xs`.
