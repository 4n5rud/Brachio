# EmptyState

What a region shows when it has nothing yet, with the one step that fills it.

## Use
- First run (no repository): the mascot peeks over a hairline, then a title, one sentence on how Brachio works, and the action. This is the only place the mascot appears inside the app.
- Smaller regions (an empty list, no changes yet) show a title line and an action, with no mascot.
- Title in `heading`; the sentence in `label` `color-text-3`, at most 40 characters per line.

## Don't
- Don't add illustrations or other mascot poses.
