# DiffStat

Added and removed line counts for a task's branch.

## Use
- `meta` style. `+N` in `color-add`, `−N` in `color-del`, written with a true minus sign (U+2212).
- In task rows, the task header and tiles. Hidden while the branch has no changes, rather than showing +0 −0.
- Counts above 9,999 show as `+12.4k`.
